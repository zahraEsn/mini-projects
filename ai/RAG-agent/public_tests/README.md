# راهنمای اجرای تست‌های عمومی

## اجرا

```bash
python public_tests/run_all.py
```

## نکته مهم

در این تست‌ها، سرویس جستجو به صورت **mock** شبیه‌سازی می‌شود و از فایل
`input_data/documents.json` می‌خواند. نیازی به اتصال به سرویس واقعی نیست.
مدل زبانی با کلید و آدرسی که در `.env` وارد کرده‌اید کار می‌کند.

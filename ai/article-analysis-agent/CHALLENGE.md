# چالش: عامل هوشمند تحلیل و مرور مقالات علمی

## شرح مسئله

با افزایش حجم مقالات علمی منتشرشده، پژوهشگران برای مطالعه، مقایسه و استخراج اطلاعات کلیدی از منابع علمی با چالش‌های متعددی مواجه هستند.

در این چالش باید یک **عامل هوشمند (Agent)** طراحی و پیاده‌سازی کنی که با دریافت مجموعه‌ای از مقالات علمی، یک **گزارش تحلیلی جامع** تولید کند.

هدف این عامل تنها خلاصه‌سازی مقالات نیست؛ باید بتواند:
- اطلاعات کلیدی مقالات را استخراج و مقایسه کند
- روندها و الگوهای مشترک بین مقالات را تحلیل کند
- شکاف‌های پژوهشی موجود را شناسایی کند
- یافته‌های نهایی را جمع‌بندی کند

---

## ابزارهای آماده‌ای که در اختیار داری

دو فایل به تو داده شده که **باید عیناً از آن‌ها استفاده کنی** — دوباره‌نویسی نکن:

### ۱. `pdf_to_markdown.py` — تبدیل PDF به Markdown

```python
from pdf_to_markdown import convert_folder

articles = convert_folder("input_pdfs/")
# articles: list[ArticleMarkdown]
for a in articles:
    print(a.filename, a.markdown[:200])
```

### ۲. `rhino_provider.py` — اتصال به مدل ما (Rhino)

برای این چالش باید از **مدل اختصاصی ما (Rhino)** که از طریق API Key در اختیارتان قرار گرفته استفاده کنی — نه از OpenAI، Anthropic یا هر سرویس دیگر.

```python
from rhino_provider import RhinoProvider

provider = RhinoProvider()

response_text = await provider.complete([
    {"role": "system", "content": "تو یک دستیار تحلیل‌گر علمی هستی."},
    {"role": "user", "content": "این متن را تحلیل کن: ..."},
])
```

توکن و آدرس سرویس از طریق فایل `.env` (طبق نمونه `.env.example`) خوانده می‌شود — مقادیر واقعی هنگام برگزاری چالش به تو داده می‌شود.

> ⚠️ `pdf_to_markdown.py` و `rhino_provider.py` را تغییر ندهید.

## ترتیب اجرا (دو مرحله)

برنامه شما باید **دو مرحله جداگانه** را پشت‌سرهم انجام دهد:

کلاس `Agent` با متد `run` باید این محتوای Markdown را بگیرد و گزارش نهایی را بسازد.

```python
        """

```

نحوه اجرای کلی برنامه از خط فرمان:

```bash
python agent.py --input_folder <مسیر فولدر PDF> --output <مسیر فایل خروجی .md>
```

## خروجی مورد انتظار

خروجی باید **یک فایل Markdown** با ساختار زیر باشد:

```markdown
# عنوان گزارش

## خلاصه اجرایی
(۱۵۰ تا ۳۰۰ کلمه — مهم‌ترین یافته‌ها)

## ۱. جدول استخراج اطلاعات کلیدی
(جدول مقالات — هدف، نوع مطالعه، روش‌شناسی، نتایج، محدودیت‌ها و ...
اگر اطلاعاتی در مقاله نبود، بنویس "ذکر نشده است" — از حدس زدن خودداری کن)

## ۲. تحلیل روندهای پژوهشی
(حداقل دو نمودار تحلیلی + تفسیر نتایج آن‌ها)

## ۳. شکاف‌های پژوهشی
(حداقل سه شکاف پژوهشی، هرکدام با توضیح اینکه بر چه شواهدی مبتنی است
و چرا اهمیت دارد)

## نتیجه‌گیری
(جمع‌بندی مختصر، منسجم و مستند از مهم‌ترین یافته‌ها و چالش‌ها)

## منابع / مستندات پایه
(فهرست مقالات استفاده‌شده)
```

> خروجی باید **کاملاً فارسی** و **یک فایل Markdown واحد** باشد.

## آزادی در انتخاب

- **استخراج متن از PDF و اتصال به LLM:** ثابت است (`pdf_to_markdown.py` و `rhino_provider.py`) — این دو بخش آزاد نیستند
- **Framework Agent:** می‌توانی از LangChain، LangGraph، CrewAI، AutoGen یا هیچ framework خاصی استفاده کنی
- **معماری agent:** یک LLM call، چند مرحله، multi-agent — هرچه بهترین نتیجه را برایت دارد
- **روش ساخت نمودارها:** هر کتابخانه‌ای که می‌خواهی (matplotlib، رسم متنی، و ...)

## امتیازدهی

ارزیابی بر اساس موارد زیر انجام می‌شود:

- صحت و کامل بودن اطلاعات استخراج‌شده از مقالات
- پوشش و استفاده از تمامی مقالات ورودی
- کیفیت مقایسه و تحلیل روندها
- اعتبار و مستند بودن شکاف‌های پژوهشی شناسایی‌شده
- انسجام، ساختار و خوانایی گزارش نهایی
- پایبندی به اطلاعات موجود در مقالات (عدم تولید اطلاعات غیرمستند)

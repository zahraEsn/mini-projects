# اجرای تست‌های عمومی

از ریشه پروژه اجرا کنید:

```bash
python public_tests/run_all.py
```

این تست‌ها فقط بررسی اولیه هستند و همه معیارهای ارزیابی نهایی را پوشش نمی‌دهند.

خروجی:

- اگر همه تست‌ها موفق باشند، پیام `Passed` نمایش داده می‌شود.
- اگر تستی شکست بخورد، نام تست و پیام خطا در ترمینال و فایل `public_test_results.json` ثبت می‌شود.

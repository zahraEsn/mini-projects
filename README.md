# Mini Projects With Python

A collection of small hands-on projects built while learning and practicing different concepts in AI, Machine Learning, Data Science, and Software Engineering.

## Repository Structure

```text
mini-projects/
├── python/
├── ai/
├── machine-learning/
└── ...
```

Each project lives in its own directory and includes its own source code and documentation.
